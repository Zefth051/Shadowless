Instant Replay that tries to stay on.

PIPELINE STATE VISIBLE
01 / THE MOMENT

Replay failure is easy to miss.
The moment is not.

A game crashes. A source disappears. A graphics driver restarts. If recording stops quietly, the only warning arrives after you press Save.

Shadowless is built around supervision: show the real state, attempt a controlled restart, then retry instead of pretending the buffer is healthy.

Recovery reduces lost footage. It cannot recreate frames Windows, a game, anti-cheat software, or a failed driver never delivered.

02 / THE RECOVERY LOOP

Always checking.
Never claiming blindly.

Rolling capture and recovery are treated as one system.

  1. 01 Buffer armed

    Compressed video and audio packets stay in RAM until you save.

  2. 02 Stall detected

    Watchdog checks for a stopped module or missing new frames.

  3. 03 Controlled retry

    Shadowless restarts the pipeline, reports failure, and backs off between retries.

  4. 04 Recording again

    The optional click-through indicator shows when replay is active, recovering, unavailable, or saved.

03 / CAPTURE PATH

Desktop coverage.
Direct game capture.

A

Desktop mode

Records your selected monitor, uses direct Game Capture when usable, and keeps desktop video active when a game cannot be hooked.

B

Game Capture mode

Keeps a low-rate detector ready while the buffer sleeps, then wakes for a plausible game. The desktop is never recorded.

04 / HARDWARE ENCODING

Use the encoder your GPU exposes.

Shadowless detects available hardware encoders and hides unsupported codec choices.

01

AV1

Best compression on supported modern hardware. Newer format; check player and editor support.

02

HEVC

Strong compression with broader modern-GPU support than AV1.

03

H.264

Most compatible choice for playback, editing, and sharing.

Encoder families implemented: NVIDIA NVENC · AMD AMF · Intel Quick Sync

Know before installing

  • GitHub release binaries are not Authenticode-signed. SmartScreen may show “Unknown publisher.”
  • Some games or anti-cheat configurations may block Game Capture.
  • DRM-protected regions may appear black. Shadowless does not bypass DRM.
  • Desktop capture cannot create unique frames beyond the desktop presentation rate.

Verify downloads with SHA256SUMS.txt and GitHub build provenance.

12 / FAQ

Before you press download.

Is Shadowless a full OBS Studio replacement?

No. Shadowless uses libobs, but deliberately omits scenes, streaming, transitions, and plugin management. It is focused on Instant Replay.

Which download should I choose?

When reviewed packages are published, use the Setup EXE for a normal per-user installer and uninstaller. Use Portable ZIP for a movable folder; extract the entire archive before launching Shadowless.exe.

Can Shadowless record only selected applications?

Yes. Per-application audio routing can assign individual running apps and the microphone to available recording tracks. The selected audio codec and container determine how many tracks are available.

Which interface languages are available?

English, Russian, Ukrainian, Simplified Chinese, Spanish, Brazilian Portuguese, German, French, Japanese, Korean, and Polish. First launch follows Windows when its language is supported.

Does Shadowless upload clips or use telemetry?

No. Shadowless has no cloud clip service, account, analytics, advertising, telemetry, or automatic upload. Non-Store builds may contact GitHub for update checks.

Will it work on AMD or Intel graphics?

Shadowless hardware testing is limited to the Linux branch on an NVIDIA GeForce GTX 1650 with Hyprland / Wayland and GSR. Other GPUs and Windows capture remain unvalidated by this project. RTX test reports belong to Captail on Windows, not Shadowless. Automated Windows package upgrade checks do not validate GPU capture.

Why does Windows show an unknown-publisher warning?

GitHub release binaries are not Authenticode-signed yet. Verify the package against SHA256SUMS.txt and GitHub build provenance before running it.

Can recovery guarantee every replay?

No. Shadowless can detect some stopped or stalled pipeline states and attempt recovery. It cannot recreate frames never delivered by Windows, the game, anti-cheat software, or a failed graphics driver.

How do I upgrade from an older upstream build?

Older upstream versions reported a file-lock bug. Use the matching Shadowless package for a manual upgrade when available. That is inherited upstream history; real in-app upgrades of Shadowless remain untested.
